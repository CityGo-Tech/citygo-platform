# CityGo Mobile

Expo SDK 57 / React Native 0.86. Клиент использует общие контракты, API-клиент,
токены и native-компоненты. Реализованы вход, сессия в SecureStore,
план, квесты, потоковый чат и завершение с XP. Обязательной анкеты нет.

«Мой план → Открыть мои шаги» показывает личные шаги того же аккаунта:
общий прогресс, фильтры, следующие страницы, отметку выполнения и возврат
в работу. Эти шаги не начисляют XP. Создание и редактор текста пока находятся
в веб-версии; экран содержит переход в неё. Данные не сохраняются локально,
запросы отменяются при закрытии экрана, выходе и смене фильтра.
Подробнее: [нативный личный план](../../docs/implementation/native-personal-plan.md).

Это мобильный прототип текущего пути. Новый постепенный R1 ещё не подключён.
[Статус проекта](../../docs/project-status.md) · [план Android](../../docs/roadmap.md#5-после-устойчивого-web-пилота).

## Локальный запуск

Команды выполняются из **корня monorepo**, после установки зависимостей.
Сначала соберите общие пакеты:

```sh
pnpm build
```

Задайте `EXPO_PUBLIC_API_URL` и `EXPO_PUBLIC_WEB_URL` в корневом `.env.mobile`,
взяв за основу `.env.mobile.example`. Это публичные адреса API и Web, не ключи.
Web-адрес указывает на корень сайта, без `/api`, логина, query и fragment.
Он используется для регистрации и правовых документов; отдельный API-сервер
эти страницы не обслуживает. При отсутствии Web-настройки сохраняется прежний
адрес `https://app.ситиго.рф`. Launcher разрешает только эти URL и настройки
инструментов разработки; автоматическое чтение
dotenv в Expo отключено. Не создавайте `apps/mobile/.env` с секретами.

| Устройство                                        | Адрес API                                                                                                              |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| Android-эмулятор на компьютере с локальным API    | `http://10.0.2.2:4000`                                                                                                 |
| Физический телефон в согласованной локальной сети | IP компьютера и порт API; серверу нужен `API_HOST=0.0.0.0`, firewall ограничивается нужным устройством                 |
| Удалённое тестирование / установленная сборка     | Согласованный HTTPS-адрес; через Web-прокси URL включает `/api`, при прямом API-префиксе следуйте конфигурации ingress |

Запустите API по [локальной инструкции](../../docs/runbooks/local-development.md),
затем в другом терминале:

```sh
pnpm mobile:dev
```

Metro обслуживает приложение для совместимого Expo Go/устройства. На телефоне
`localhost` — сам телефон, не компьютер. Устройства должны иметь сетевой доступ
друг к другу; публичный dev-сервер не заменяет production-развёртывание.

SDK 57 предоставляет streaming fetch на native. Секреты RouterAI/OpenAI/GigaChat
остаются на API; никакой `EXPO_PUBLIC_*` не должен содержать ключ.

Для Android-эмулятора пара адресов — `http://10.0.2.2:4000` (API) и
`http://10.0.2.2:3000` (Web). Для физического телефона укажите доступный ему
адрес компьютера отдельно для обоих портов; для публичного reverse proxy —
HTTPS-адрес API с нужным префиксом и корневой HTTPS-адрес Web.

## Проверка и распространение

```sh
pnpm mobile:export
```

Команда проверяет Android/iOS **JS-бандлы**, не собирает подписанный APK/IPA.
Она не создаёт EAS-проект и не публикует приложение.

Для установки на Honor 200 без компьютера/Expo Go нужны отдельная подписанная
preview-сборка, корректный HTTPS API, проверка нового жилищного пути,
холодного старта, обновления, TalkBack, слабой сети и отзыва сессии.
Это задачи CG-045–049. Проект/подписи принадлежат владельцу; ключи не хранятся
в Git. iOS и магазины требуют отдельной приёмки и доступов.

Основной Web находится в `apps/web`; этот Expo-пакет не заменяет его.

## Первый выбор нового режима

Когда сервер включает каталог режимов, действующий пользователь может выбрать
новый режим прямо в Expo-приложении. Окно показывает актуальную редакцию условий
по ссылке и в свёрнутом тексте. Переключатель изначально выключен. После явного
подтверждения клиент сохраняет выбор для того же аккаунта и проверяет обновлённый
каталог. Новый режим выбирается только после этой проверки; сообщение само
не отправляется. Актуальное согласие регистрации не требует повторного POST.

Отмена сохраняет прежний режим и сообщение. Выход, смена сессии и отмена при
ожидании ответа не позволяют позднему ответу выбрать режим. Рекламное согласие
не меняется. При ошибке нет автоматического повторного сохранения.

Проверки логики выполняются через `pnpm --filter @citygo/mobile test`;
`pnpm mobile:export` проверяет совместимость JS-бандлов Android/iOS. Экспорт
не подтверждает поведение настоящего устройства, экранного диктора или
подписанной сборки. Изменение клиента само не включает серверные режимы.
