# Пакет Web/API по Figma

Три фичи развиваются в отдельных PR от принятого main 13d238b.
Они затрагивают общий ConversationHome, поэтому ветки расположены цепочкой:
`codex/web-support-requests` → `codex/web-material-preview` → `codex/web-results-library`.
Diff каждого PR относительно предыдущей ветки содержит собственную фичу.
Совместный прогон проверяет точную вершину, включающую все три.

## Пользовательские сценарии

- [Помощь человека](human-support-requests.md), Figma 6:72/6:73: пользователь
  сохраняет свой вопрос без AI-запроса и платного баланса. Администратор читает
  обращение и явно закрывает или открывает его. Пользователь видит сохранённый
  статус. История чата автоматически не прикладывается; писем и SMS этот путь
  не отправляет. Нужна миграция 0037 с ограниченными правами API, без прав Worker.
- [TXT-материал](text-material-preview.md), Figma 6:80/6:81: файл читается локально,
  пользователь проверяет и редактирует текст, затем явно добавляет его к текущему
  черновику. Обычная кнопка отправки остаётся отдельным действием. Поддерживается
  UTF-8 TXT, а не разбор PDF/DOCX. Общий лимит вопроса сохраняется; молчаливой
  обрезки, загрузки файла на сервер и отдельного тарифа нет.
- [Результаты](results-library.md), Figma 6:28: реальные шаги плана и избранные
  сообщения доступны карточками с независимыми страницами, источником,
  возвратом к списку и явной локальной выгрузкой .txt. Новые вымышленные планы,
  резюме или подборки Bubble не создаются. Существующее управление избранным
  и личным планом сохраняется.

Данные вопросов, материалов, контактов и сохранённых сообщений скрываются
от Метрики по существующим private-классам. Сессии и ответы проверяются до
публикации в интерфейсе; поздний ответ не переходит к следующему владельцу.

## Приёмка и границы

У каждой ветки есть целевые unit/HTTP/PG/браузерные проверки и визуальная
проверка desktop/mobile-web. На объединённой вершине выполняются все семь
CI-команд и шесть Container smoke-команд из scripts/operator-release.mjs.
Пропуски и flaky-результаты в общем прогоне не принимаются; discovery включает
все исходные тесты. Новые обязательные сценарии дополнительно проверяются
по фактическим успешным названиям в логе.

Используются только синтетические БД, данные и ключи. Рабочие API провайдеров,
реальные оплаты и сообщения не вызываются. Публикация образов, слияние PR,
обновление сервера и включение автодеплоя не входят в этот этап. Результат
локальных проверок не является разрешением на выпуск. Следующий выпуск
потребует проверки итогового main и свежей резервной копии с восстановлением.

Сохраняются три режима ИИ, резерв 5 ₽ CityGo, RouterAI ×10, фиксированная плата
«Минимума», ЮKassa с чеками, подтверждение телефона и разовый подарок 500 ₽.
Expo PR #135, память PR #119 и карьерные факты PR #128 не входят в этот пакет.
