## Удалённый шаг плана

Если шаг удалён в другой вкладке, чтение чек-листа отвечает 404. Раньше
это включало обязательную сверку и одновременно блокировало обновление
родительского списка: повторное чтение отсутствующего шага не помогало.

Ресурс различает подтверждённую недоступность шага (`missing`) и неизвестный
результат операции (`needsRefresh`). После 404 устаревшие пункты очищаются,
сохранение запрещено, но список плана можно обновить без ухода с экрана.
Открытый редактор сохраняет введённый текст до явной отмены; решение об
удалении пункта также можно явно отменить. Пока такой черновик или решение
не закрыты пользователем, защита от потери изменений остаётся активной.

409, сбой транспорта и неподтверждённая запись по-прежнему требуют чтения
перед следующей записью. Повторной автоматической записи нет. 401/403,
смена владельца, отмена сессии и поздние ответы обрабатываются прежними
проверками. Недоступность одного шага не завершает аккаунтную сессию.

## Источник из загруженной истории

Подготовка разговора с другим помощником проверяет источник по той же
авторизованной проекции истории, которая отображается в Web. Поэтому
сообщение из ранее загруженной страницы не теряется при проверке только
последней страницы диалога.

Совпадение владельца, диалога, помощника, сессии, ID, точного текста и
завершённого статуса остаётся обязательным. Подготовленный фрагмент
добавляется к существующему черновику целевого диалога; исходный черновик
сохраняется. Это действие не отправляет сообщение модели и не списывает
деньги. Смена аккаунта убирает форму и исключает перенос прежнего текста.

## Проверки и эксплуатация

Регрессии покрывают 404 при чтении и сохранении, восстановление списка,
явную отмену сохранённого в форме черновика, неопределённый результат
записи и успешную последующую сверку. Браузерные проверки передачи используют
настоящую последовательность загрузки старой страницы, редактирования
фрагмента, подготовки целевого черновика и перезагрузки страницы.
Все аккаунты, ответы API и провайдеры в проверках синтетические.
Точные результаты локальных прогонов указываются в PR для его SHA.
