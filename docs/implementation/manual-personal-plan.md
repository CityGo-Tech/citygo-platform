# Собственные шаги личного плана

В «Моём плане» кнопка «Добавить шаг» открывает существующий редактор названия и описания. Пользователь может сохранить действие без сообщения помощника. Такие карточки помечены «Ваш шаг» и не показывают вымышленный источник. Шаги из сообщений сохраняют прежнюю ссылку на диалог.

`POST /v1/personal-plan` принимает явное `sourceMessageId: null` для самостоятельного шага; отсутствие поля остаётся ошибкой. Ответ имеет `source: null`. Старые запросы со строковым ID не меняются. Стабильный `operationId` связывает исходный нормализованный запрос: повтор не создаёт дубликат, не меняет источник и не восстанавливает удалённый шаг. Статус, редактирование и удаление сохраняют CAS по revision, предел 200 активных шагов и проверку владельца.

Миграция 0038 снимает NOT NULL только с source_message_id и обновляет guard: непустая ссылка по-прежнему требует сообщение этого владельца; источник остаётся неизменяемым. Новых таблиц, ролей или SQL-прав нет. Результаты, общий контроллер плана и Web корректно читают null. Данные шага скрыты от Метрики. Действия не вызывают AI, платежи, SMS, email и не меняют квесты или XP.

Визуальная основа — Figma 6:24: существующие карточки, отступы, Manrope и токены CityGo. Новый редактор использует имеющиеся Button/Card/Field. Это расширение рабочего плана, а не демонстрационные данные из прототипа.

Проверки: контракты/клиент, PGlite CRUD/replay/ownership/CAS/guard, HTTP без моделей и денег, сохранение данных при 37 → 38, фактические права роли API и параллельный replay в disposable PostgreSQL, браузерное создание и перезагрузка. Сервер и автодеплой этим PR не меняются.
