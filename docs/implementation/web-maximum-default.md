# Начальный режим Web — Максимум

3 ноября 2026. Основа после обновления: main `923ac30`, схема 46.

При открытии аккаунта Web выбирает «Максимум». Явный последующий выбор
сохраняется при обновлении кабинета и истории; смена аккаунта сбрасывает его
на начальный режим. Чтение кабинета не отправляет сообщение и не даёт согласие.
Недоступность выбранного режима блокирует отправку, без перехода на другой.
При необходимости новых условий кнопка «Подтвердить выбор» открывает
существующее явное подтверждение даже для уже выбранного начального режима.

Это предпочтение Web, а не изменение wire-контракта. Strict-каталог сохраняет
ровно прежние поля и `defaultMode: balanced`; API-запрос без режима по-прежнему
использует прежний «Баланс». Поэтому установленный APK читает тот же ответ.
Новый Web передаёт выбранный режим и каталог при явной отправке. Runtime policy,
права, три маршрута, списание после ответа без денежного удержания, ×10 и
«Минимум» 3 ₽ не меняются.

Если старый сервер не возвращает каталог, Web не добавляет режим к запросу;
аналитика отправки и исхода указывает прежний «Баланс», а не начальное
предпочтение «Максимум». Это не меняет маршрут старого API.

Целевые проверки: unit предпочтения/селектора, API-каталог и legacy resolve;
синтетические browser-сценарии `ai-mode-default.spec.ts` и `ai-modes.spec.ts`.
Сервер, автодеплой, ЮKassa с чеками, телефон и подарок 500 ₽ не изменяются.
Результаты полного объединённого прогона фиксируются отдельно перед слиянием.
