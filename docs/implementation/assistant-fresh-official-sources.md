# Свежие официальные источники «Максимума» — 6 ноября 2026

От `main aa59501`, схема 49, подготовлена отдельная доработка инструкций
`routerai-native-web-search-instructions-v2`. При контрольном запросе о тарифе
метро помощник нашёл верное официальное объявление 2025 года и честно оговорил
неподтверждённую актуальность. Действующая официальная страница услуги давала
тот же ответ, но не была использована моделью.

## Изменение

API передаёт текущую календарную дату UTC из собственных часов только в
native-поисковый «Максимум». Инструкция добавляется **до** выбора контекста и
подсчёта токенов; отправка и офлайн-предпросмотр используют один helper.
Дата запроса не считается датой проверки сайта. Явная историческая или будущая
дата пользователя сохраняет приоритет для определения нужного периода.

Для меняющихся условий инструкции требуют искать действующую официальную
страницу услуги, тарифа или правил. Старое объявление используется для даты
введения, а не как доказательство неизменности условий. При первом результате
в виде старой новости поиск продолжается по действующему официальному разделу.
Приоритет учитывает организацию, территорию, способ оплаты и период действия,
а не только возраст публикации. Страница без даты обновления допустима, но её
нельзя автоматически объявлять свежей. Неясность и конфликт источников должны
быть явно отражены в ответе. Для обычного ответа достаточно 1–2 действительно
использованных официальных источников.

Это инструкция модели, а не собственный поисковый ранжировщик или гарантия
фактической полноты поиска. [Документация RouterAI](https://routerai.ru/docs/guides/overview/plugins/web-search)
описывает native-плагин и аннотации источников; эта доработка сохраняет тот же
плагин. Дополнительные фильтры доменов, инструмент чтения URL, повторный POST,
увеличение числа результатов или скрытый fallback не добавляются.

## Совместимость и будущий выпуск

Режимы «Баланс»/«Минимум» и профили без native-поиска сохраняют прежние байты
инструкций. Тарифы ×10 и 3 ₽, полный чек с поиском, постоплата без удержания,
ЮKassa с чеками, телефон и подарок 500 ₽ не меняются. Новых миграций нет.
Сервер, его конфигурация и автодеплой этим PR не меняются.

Статическая версия инструкции входит в descriptor исполнения, поэтому изменится
execution key native-«Максимума». Дата запроса в этот key не входит: ежедневное
обновление даты не требует изменения правил бюджета. Для будущего выпуска
нужен явный перенос полного правила Maximum на новый key с сохранением лимитов
и счётчиков; автоматический rekey и переход старых несверенных попыток запрещены.

## Приёмка

Проверки сохраняют хеши прежних инструкций; проверяют календарную дату и границу
UTC, scoped capability, системную инструкцию в штатном HTTP-пути и включение
добавленного текста в расчёт контекста. Остаются проверки одного POST, нулевого
удержания, полного точного чека и однократного списания ×10 после ответа.
Синтетические проверки не доказывают выбор реальной страницы моделью. Живая
приёмка нового SHA проводится отдельно после разрешённого выпуска; в этом PR
новых обращений к провайдеру и серверного обновления нет.
