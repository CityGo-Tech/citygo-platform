# Следующие четыре функции Web/API

Основа — main fb3ebbf после PR #145, схема 39. Подготовлены четыре отдельные ветки в порядке зависимостей:

1. `codex/plan-search-v1`: поиск по названию и описанию собственного шага вместе с существующим фильтром статуса до keyset-пагинации. [Описание](plan-search.md), Figma 6:24.
2. `codex/favorite-search-v1`: буквальный поиск избранных сообщений, помощник и автор до пагинации. Сохраняется предел страницы 6 MiB и курсор неполной страницы. [Описание](favorite-search.md), Figma 65:5343.
3. `codex/assistant-handoff-v1`: проверить и изменить выбранный фрагмент перед добавлением к черновику другого помощника. Истории и прежние черновики сохраняются; отправка остаётся отдельной кнопкой. [Описание](assistant-handoff.md), Figma 6:30/6:45/6:62.
4. `codex/message-actions-v1`: копирование и локальный UTF-8 TXT завершённого сообщения целиком, с ручным копированием при отказе буфера. [Описание](message-text-actions.md), Figma 6:52/6:28.

Миграций, новых зависимостей и изображений нет. Поисковые строки и личный текст скрыты от аналитики, URL query не сохраняется серверным журналом запросов. Отмена, смена владельца, поздние ответы и границы keyset проверяются отдельно.

У каждой ветки есть целевые проверки. На общей вершине выполняются семь канонических CI-команд и шесть Container smoke-команд с полным discovery, настоящим временным PostgreSQL и desktop/mobile-web. Результат относится к точному SHA/tree общей вершины; локальный прогон не выдаётся за успешный GitHub Actions.

Три режима ИИ, резерв 5 ₽ CityGo, действующие тарифы (RouterAI ×10, «Минимум» 3 ₽), пополнение 1:1, ЮKassa с чеками, телефон и подарок 500 ₽ сохраняются. Тесты используют синтетические аккаунты и провайдеры. Сервер, автодеплой и настоящие AI/платежи/письма/SMS не затрагиваются.
