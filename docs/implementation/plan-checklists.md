# Чек-листы внутри личного плана

Следующий этап Web/API по Figma 6:37: пользователь сам составляет пункты
подготовки внутри сохранённого шага, уточняет их и отмечает готовое. Никаких
примеров или подтверждений за пользователя автоматически не создаётся.

Кнопка «Чек-лист» открывает список внутри карточки шага. Можно добавить до 20
пунктов с названием до 120 и подробностями до 1000 UTF-16 единиц, изменить,
отметить и удалить пункт с подтверждением. Все данные скрыты от Метрики.
Отметки не завершают родительский шаг, не означают совершённую сделку,
не запускают AI и не меняют XP, подарок или финансовые записи.

GET /v1/personal-plan/:id/checklist возвращает только собственный активный шаг
и полный авторитетный список. PUT того же ресурса принимает expectedRevision
родительского шага и полный список. Только этот PUT имеет предел тела 256 КиБ; общий лимит API сохранён. Полные 20 пунктов с длинными кириллическими подробностями проходят, превышение даёт 413 без записи. Чужой, отсутствующий и удалённый шаг дают
одинаковый 404. Заголовки контракта, текущая сессия, согласия, активный аккаунт,
обязательная смена пароля и same-origin для cookie проверяются общим API.

Миграция 0039 добавляет personal_plan_checklists после зависимости 0038.
Порядок блокировок user → parent item совпадает с редактированием личного плана.
Сохранение атомарно увеличивает родительскую revision и записывает весь список.
Конкурентная или устаревшая команда получает 409. Клиент сверяет полный нормализованный список в ответе с отправленной командой. После неизвестного результата
Web требует явного обновления и не повторяет PUT автоматически. Поля владельца
не принимаются от клиента. SQL ограничивает структуру, размер, UUID-уникальность
и неизменность identity/revision; API не получает DELETE, Worker — доступа.

Клиент изолирует владельца, шаг и срок сессии; отменяет запросы и игнорирует
поздние ответы. Успешная запись перечитывает родительский список, сохраняя
открытую карточку, чтобы последующие действия использовали свежую revision.
Новые провайдеры, реальный сервер, автодеплой и существующие тарифы не меняются.
