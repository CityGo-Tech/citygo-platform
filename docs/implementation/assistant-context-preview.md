# Что помощники знают

Основа: main 686ff6a, схема 44. Ссылка Figma: файл
`6pAycf8MPlTyddwYPH6NEL`, экраны 6:14 и 6:20. Справа доступно явное
действие «Что помощники знают». Открывается отдельная панель в рабочей колонке;
черновик и выбранный разговор сохраняются.

Панель показывает только реальные сохранённые поля переезда и завершённые
пары сообщений текущего диалога, попадающие в предварительный контекст.
Неизвестные данные остаются неизвестными. Предположения модели не объявляются
подтверждёнными фактами. Это не реализация постоянной подтверждённой памяти
из отдельного PR #119 и не объединение переписки разных разговоров.

Явный POST `/v1/ai/context-preview` — операция чтения: текущий черновик
используется только для расчёта объёма контекста и не сохраняется. Применяется
тот же `buildConversationContext`, что в чате; правила/системный prompt в ответ
не возвращаются. Пока вопрос пуст, предварительный снимок пересчитывается для
небольшого служебного маркера, который не попадает ни в БД, ни в ответ.
При следующей отправке контекст строится заново по актуальному вопросу.

Проверка владельца выполняется под блокировками user → thread, а авторизация
повторяется после чтения. Нет вызовов провайдера, резерва, списания, изменения
квоты, сообщений, согласий или сохранённых сведений. Смена владельца,
разговора, закрытие панели или истечение сессии не публикуют запоздалый ответ.
Частные поля скрыты от Метрики. Новый optional dashboard capability совместим
со старым клиентом; старый API без флага не получает команду предпросмотра.

Миграций и новых SQL-прав нет. Три режима, резерв 5 ₽, тарифы, ЮKassa с чеками,
телефон и подарок сохраняются. Сервер не обновляется, автодеплой выключен.
