# CG-008 — версии контрактов и ошибки

Дата: 23 сентября 2026. Ветка `codex/versioned-contracts-cg008` от `d7f30f5`
(main после PR #36). Рабочая копия: `citygo-platform-review`.

## Результат

- Общий wire v1, заголовки версии/корреляции, явный отказ от неизвестной версии
  до исполнения команд; headerless старые клиенты поддерживаются.
- Совместимые HTTP/SSE metadata без удаления прежних `error`/`message`.
  Различаются согласие, смена AI-получателя, квота запросов, денежный бюджет,
  конфликт ревизий и транспортный обрыв. Автоматического повтора нет.
- API-клиент Web/Expo отправляет версию, проверяет ответ, сохраняет serverCode,
  requestId, retryable и currentVersion отдельно от транспортного кода.
- Runtime-схемы метаданных profile/plan/quest/artifact/run/source/case, versioned
  references и bounded pagination/command; schemaVersion отделён от revision.
- [Политика совместимости](../architecture/api-compatibility.md) описывает
  обновление/rollback и границы кандидатных R1-схем.

## Проверка

Добавлены положительные/отрицательные проверки каждой R1-схемы и transport
fixtures: старый сервер, Web/native, неподдерживаемый ответ, будущий код ошибки,
stream error без ложного done. API-тесты проверяют отсутствие регистрации/logout
при неподдерживаемой версии, CORS, серверный requestId, безопасные parsing/404
ошибки и различимость ошибок AI/CAS через реальные обработчики со стендовыми
данными и заглушкой модели.

Локально прошли `pnpm lint`, `pnpm typecheck`, `pnpm test` (включая 83 API-теста и
17 env-тестов); после финальной проверки обработки 401 отдельно прошли все
33 теста api-client, его lint и общая проверка типов. Результаты полного
GitHub CI (PostgreSQL, сборки, startup, E2E, Expo export) и автоматического review
фиксируются в PR. Полная Web-сборка локально не запускается, чтобы не перезаписать
работающий preview. Live AI и реальные ключи не используются.

## Границы и следующий шаг

Нет миграций/новых endpoints R1/изменений бюджета, провайдеров, credentials,
локальных данных или deployment. Schema parse проверяет форму, а не ownership,
свежесть источника, экспертное качество или фактическое выполнение операции.
Артефакт пока имеет только метаданные: его содержимое/приёмка — CG-010, хранение —
CG-012, начисление по evidence — CG-014. Сам по себе этот PR не делает R1 готовым.

Следующий основной шаг — **CG-009**: связь user quest с конкретным планом и
версией, совместимый backfill и сохранение старого XP на тестовой копии.
