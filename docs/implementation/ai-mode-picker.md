# Выбор режима работы по Figma

2 ноября 2026. Основа — начальный Maximum из отдельного изменения.
Экраны: [desktop](https://www.figma.com/design/6pAycf8MPlTyddwYPH6NEL?node-id=41-4293)
и [mobile](https://www.figma.com/design/6pAycf8MPlTyddwYPH6NEL?node-id=41-4344).

Вместо системного select — кнопка «Режим работы» и диалог с тремя карточками.
На desktop панель шириной 416 px; на mobile — нижняя панель во всю ширину.
Используются Manrope, общие цветовые токены, Button и радиусы прототипа.
Названия — «Максимум», «Баланс», «Минимум»; последнее сохраняет явный выбор
владельца вместо демонстрационного «Базовый». Описания объясняют тип задач,
без моделей, провайдеров и внутренних расчётов. Статические assets не требуются.

Открытие, закрытие, Escape и клик вне панели не выбирают режим и не выполняют
HTTP-команд. Карточка изменяет только следующее явное сообщение. Уже выбранную
карточку можно нажать для существующего подтверждения новых условий; согласие
никогда не даётся автоматически. История, черновик, busy-guards, ID каталога,
стоимость и прежний отказ без fallback сохраняются.

Native dialog удерживает фокус, Escape закрывает его и возвращает фокус кнопке.
Карточки — native buttons с aria-pressed; Tab/Shift+Tab, Enter/Space доступны.
У каждой копии компонента собственные useId/refs, поэтому inline и боковая
кнопки могут использовать один выбор без повторяющихся DOM id.

Компонент AiModeSelector сохраняет props modes/selected/disabled/onSelect и
добавляет необязательный className. Родитель владеет выбранным режимом и
согласиями. Модуль не меняет conversation-home/workspace-frame и сервер.
Тесты: semantic unit, guards состояния, синтетические browser-сценарии выбора,
согласий, ошибок, смены аккаунта, keyboard/focus, mobile layout и busy.
Финальные результаты объединённого прогона фиксируются отдельно.

API wire-контракт остаётся прежним. Тарифы, резерв 5 ₽, ×10, ЮKassa с чеками,
телефон и подарок 500 ₽ не меняются. Слияние, выпуск и автодеплой не выполняются.

## Локальная проверка двух изменений

На собственных frozen workspace dependencies: 20/20 целевых unit/API/client
тестов, Web production build и Web typecheck — успешно. Точечные ESLint,
Prettier и git diff --check пройдены.

Свежий повтор шести затронутых browser-specs — **64/64**, desktop и mobile,
без повторных попыток, ошибок и пропусков. Использован официальный Chrome for
Testing/Headless Shell **156.0.8078.4**, Playwright revision 1248. Проверены
начальный Maximum, согласия/отмена, недоступность без fallback, поток и busy,
смена аккаунта, восстановление черновика, handoff, приватность материала,
Tab/Shift+Tab, Escape, фон, возврат фокуса и размеры панелей.

Все запросы в browser-сценариях синтетические; внешние назначения блокируются.
Это целевые проверки двух изменений, а не полный Linux/PostgreSQL релизный
прогон и не Container smoke. Полный объединённый набор проверяется отдельно.
