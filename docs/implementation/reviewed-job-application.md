# CG-040 · Черновик отклика на выбранную вакансию

Из «Результаты → Открыть полностью» откройте сохранённое резюме и выберите
«Сравнить с вакансией». Введите название вакансии и до шести требований.
Для каждого требования можно выбрать фрагмент сохранённого опыта. В разделе
«Что нужно уточнить» остаются требования без выбранного подтверждения.

«Проверить отклик» открывает редактируемый текст с выбранными фактами. Его
можно скопировать и использовать на площадке вакансии. Вакансию вводит
пользователь. Сетевой поиск, вызовы моделей и отправка откликов относятся
к отдельным задачам.

Действие доступно в открытом результате, связанном с сообщением пользователя.
Пользователь сам выбирает результат как основу для резюме, а затем отмечает
подходящие фрагменты. Изменение названия сохранённого результата не меняет
доступность перехода. Текст вакансии и отклика хранится в открытой форме.

Перед показом сравнения, подготовкой и копированием используется существующее
чтение результата с проверкой владельца. Если ревизия изменилась или чтение
завершилось ошибкой, копирование приостанавливается. При закрытии формы
для изменившейся ревизии список перечитывается.

Приёмка на синтетических данных проверяет ручной выбор фактов, видимость
неподтверждённых требований, редактирование и явное копирование. Отдельный
сценарий изменяет ревизию между подготовкой и копированием.
