# Неотправленный текст диалога

Figma 6:76/6:77: текст остаётся черновиком, пока пользователь сам не отправит
его. Web сохраняет только поле вопроса в sessionStorage текущей вкладки,
отдельно для владельца и диалога, на 24 часа. После перезагрузки текст
восстанавливается только после серверной проверки доступа к открытому диалогу.
Сообщение о восстановлении предлагает проверить текст или удалить черновик.

Выход, смена аккаунта и необходимость заново принять условия очищают черновики.
Недоступное хранилище не блокирует обычное общение. Черновики не синхронизируются
между устройствами и вкладками; после закрытия вкладки восстановление зависит
от поведения браузера. Потоковый ответ и ожидающее сообщение не сохраняются.
Отправка остаётся явной: перезагрузка не вызывает AI-запрос и списание.

Проверки покрывают разделение владельцев/диалогов, TTL, повреждённое хранилище,
очистку, восстановление после перезагрузки и отсутствие сетевой отправки.
Тарифы, режимы, резерв, платёжные чеки, телефон и подарок не меняются.
