# Текст сообщения под рукой

Срез Figma 6:52/6:28: законченный текст можно использовать дальше. В существующем разговоре добавлены явные «Копировать текст» и «Скачать .txt» под завершёнными сообщениями пользователя и помощника. Поток, предварительный ответ и прерванная попытка не выдаются за завершённый материал. Скачивается одно выбранное сообщение, без обещания полной выгрузки истории.

Используются существующие Button/ghost, Manrope, оболочка и оригинальные портреты/логотип. Новые изображения и зависимости не добавлены. Изменяется только блок действий, а не весь экран прототипа.

Текст копируется и скачивается полностью и буквально: Unicode, переводы строк и Markdown сохраняются; HTML не исполняется. Скачивание создаёт локальный UTF-8 Blob с расширением .txt; имя зависит только от канонического ID сообщения. Object URL освобождается. Если буфер обмена недоступен, показывается выделяемое readonly-поле для ручного копирования.

Действия связаны с владельцем, сессией, разговором, сообщением и его содержимым. Отложенные результаты после выхода или смены области не показываются. Повторный клик во время копирования не запускает вторую операцию. Содержание и запасной ввод закрыты от Метрики существующими private-классами. Clipboard и файл создаются только по явному действию.

API, схема 39, три режима ИИ, резерв 5 ₽ CityGo, RouterAI ×10, фиксированные 3 ₽ «Минимума», ЮKassa с чеками, телефон и подарок 500 ₽ сохраняются. Сохранение текста не вызывает AI, платежи, SMS, письма или серверные мутации. Выпуск и автодеплой этим PR не включаются.
