# Личные названия разговоров

Пользователь может задать или изменить название разговора в списке «Диалоги» и вернуть исходное название помощника. Это функциональное продолжение карточек Figma `6:26`, с существующими Card/Button/Field и токенами приложения. Макет не выдаётся за уже содержащий кнопку переименования.

Название хранится отдельно в `conversation_titles` (миграция 0044); новые таблицы не заполняются вымышленными названиями. Очистка сохраняет ревизию, поэтому старая вкладка не перезапишет новое значение. Чтение/изменение доступны только владельцу; активность и обязательная смена пароля повторно проверяются под блокировкой. Чужой и отсутствующий разговор дают одинаковый 404, даже администратору. Разрешено переименовывать закрытую историю.

GET/PATCH `/v1/conversations/:id/title` используют десятичную bigint-ревизию. PATCH требует `expectedRevision` и возвращает 409 при устаревшем состоянии. Повтор неизменённого значения не меняет ревизию/дату. Название — одна строка, до 80 UTF-16 единиц, с сохранением Unicode; управляющие символы и непарные суррогаты запрещены. Поля `customTitle`/`titleRevision` в списке опциональны для старых клиентов/серверов. При отсутствии поддержки кнопка не показывается. Без личного названия остаётся прежний заголовок помощника.

Редактор явно загружает текущую ревизию, блокирует повторный запрос и после конфликта требует обновить название. Отмена/Escape возвращают фокус. Данные формы и заголовки скрыты от записи Метрики. Поздние ответы после смены аккаунта или закрытия редактора не восстанавливают его состояние.

Не меняются содержимое/контекст/время/порядок диалогов, сообщения, ИИ-режимы, резерв 5 ₽, тарифы, чеки, оплата, телефон и подарок. Название не отправляется модели. Применённые миграции 1–43 неизменны; runtime API получает только SELECT, INSERT трёх полей и UPDATE названия/ревизии новой таблицы. Worker и PUBLIC не получают доступ. Операторские reset-инструменты и синтетические upgrade-фикстуры распознают новые метаданные и запрещают их незаметное удаление.

Серверное обновление и включение автодеплоя в этот PR не входят.
