# CG-050 · Локальный короткий список жилья

Путь эксперимента: сохранённый стартовый план → до трёх вариантов →
учебный оригинал → явный переход к чек-листу просмотра. Используются
точная ревизия и поля уже сохранённого плана из PR #219. Город сравнивается
точно, месячная аренда проверяется по бюджету, если он указан. Свободный
ориентир поездок требует отдельной проверки маршрута.

Вход расположен в сохранённом плане [Figma 6:34](https://www.figma.com/design/6pAycf8MPlTyddwYPH6NEL/CityGo?node-id=6-34).
Карточки используют оформленные в Web компоненты плана и паттерн
[Figma 6:35](https://www.figma.com/design/6pAycf8MPlTyddwYPH6NEL/CityGo?node-id=6-35).
Источник и дата показаны по принципу [Figma 6:82](https://www.figma.com/design/6pAycf8MPlTyddwYPH6NEL/CityGo?node-id=6-82).
Архитектура относит предложения к этапу проверки источников, разрешений и
обновлений. [Miro](https://miro.com/app/board/uXjVGzVrccU=/?moveToWidget=3458764685945651733)

## Источник и ограничения

В локальном каталоге импорт партнёрской выгрузки Циана ожидает файл. Разовая
операторская выборка существует, а допуск к регулярной поставке и показу
карточек в CityGo пока не подтверждён. Эксперимент использует один вымышленный
источник «Демонстрационная выгрузка». Правила полного и частичного снимка
взяты из операторского импорта. Поле цены в этой локальной проекции допускает
`null` для проверки качества данных. Формат операторского импорта и его база
отдельны от эксперимента.

- Повтор старого снимка сохраняет прежнюю дату. Полный снимок снимает пропуски,
  а частичный сохраняет последнее наблюдение. Небезопасная ссылка делает снимок
  непригодным целиком, поэтому пропуски в таком снимке ничего не снимают.
- Дубли по ссылке отображаются по последнему наблюдению. Учебный порог
  актуальности 24 часа считается по времени демонстрационного снимка.
- При заданном потолке вариант без цены не участвует в подборе. При открытом
  бюджете он может совпадать по городу и показывает «Цена не указана».
- Учебный оригинал открывается отдельно на локальном адресе. Даты и цены
  принадлежат вымышленным объявлениям. Доступность и расходы из них не следуют.

## Локальная приёмка

Запустите Web и API по [локальной инструкции](../runbooks/local-development.md).
На домашней странице Web в браузере откройте
`http://localhost:3000/?housingCatalogDemo=1`. В тестовом аккаунте сохраните
план для Москвы с месячным бюджетом 60 000 ₽ и откройте «Посмотреть короткий
список». Появится одна карточка «Квартира у метро» с ценой, источником и временем
наблюдения. Откройте оригинал, затем чек-лист просмотра. До явного сохранения
записей план или чек-лист не меняются. Сохраните план без потолка и повторите:
появится вариант без цены и пометки о совпадении с бюджетом.

При изменении плана в другой вкладке список прежней ревизии закрывает карточки
после актуализации. Ошибка при перечитывании тоже скрывает карточки до успешной
проверки. Для новой версии нужно снова открыть список. Вход в демо
доступен только на loopback Web по явному параметру в адресе. В мини-приложениях
по этому параметру раздел не появляется.

## Измерение пользы и допуск источников

В закрытой приёмке посчитайте долю тестовых сессий, где после первого показа
непустого списка человек явно выбрал следующий шаг, например перешёл из
списка к чек-листу просмотра. Посчитайте открытия оригинала отдельно как
диагностический сигнал. Фиксируйте пустую выдачу отдельно и учитывайте каждую
сессию один раз. Само открытие оригинала не подтверждает результат или XP.
Для этого эксперимента достаточно локального журнала приёмки с булевыми
результатами и числом карточек. Тексты, ссылки, суммы и значения критериев в
журнал и Метрику не передаются.

| Критерий | Что проверить перед подключением                                                                           |
| -------- | ---------------------------------------------------------------------------------------------------------- |
| Доступ   | Договор, условия API или фида, разрешение на показываемые поля, ссылку и обновление.                       |
| Полнота  | Доли записей с известной месячной ценой, достоверной локацией и ссылкой на карточку.                       |
| Свежесть | Реальное время наблюдения, задержка доставки, реплей, снятия в полном снимке и правила частичной поставки. |
| Польза   | Доля непустых списков и доля явных следующих шагов по тому же сценарию.                                    |

Оценка реального партнёрского фида относится к CG-050–052. Массовый сбор с
агрегаторов и из социальных сетей в эксперимент не входит.
