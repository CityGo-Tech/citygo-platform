# Мини-приложения CityGo

Первый этап по [прототипу Figma](https://www.figma.com/design/xnlvdm113tfcHbZO5bekdg?node-id=4-42)
добавляет гостевой экран Telegram по адресу `/mini/telegram`. Можно выбрать
задачу, получить стартовый план поиска жилья с необязательными ориентирами
или начать оценку переезда. Введённые ориентиры живут в памяти экрана.

Данные запуска из Telegram SDK выбирают только одну из существующих задач.
По нажатию клиент открывает CityGo во внешнем браузере, передавая задачу
для возврата после новой регистрации. Содержимое формы и данные профиля
мессенджера в переходе отсутствуют. Вход и регистрация используют действующий
Web CityGo. При ошибке SDK экран предлагает открыть CityGo из бота заново.

В обычном браузере адрес открывает гостевой просмотр без SDK. Настройка
бота и запуск внутри iframe браузерной версии Telegram остаются за рамками
этого этапа. Чаты, постоплата, платежи, чеки и подарок доступны в Web CityGo.
Для будущего пополнения внутри Telegram нужны
[Telegram Stars](https://core.telegram.org/bots/payments-stars#faq).
