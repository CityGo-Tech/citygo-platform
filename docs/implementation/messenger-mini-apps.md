# Мини-приложения CityGo

Первый этап по [прототипу Figma](https://www.figma.com/design/xnlvdm113tfcHbZO5bekdg?node-id=4-42)
добавляет гостевой экран Telegram по адресу `/mini/telegram`. Можно выбрать
задачу, получить стартовый план поиска жилья с необязательными ориентирами
или начать оценку переезда. Введённые ориентиры живут в памяти экрана.

Данные запуска из Telegram SDK выбирают только одну из существующих задач.
По нажатию клиент открывает CityGo во внешнем браузере, передавая задачу
для возврата после новой регистрации. Содержимое формы и данные профиля
мессенджера в переходе отсутствуют. Вход и регистрация используют действующий
Web CityGo. При ошибке SDK экран предлагает открыть CityGo из бота заново,
а гостевые шаги остаются доступны. Кнопки «Назад» в CityGo и мессенджере
возвращают на предыдущий шаг.

В обычном браузере адрес открывает гостевой просмотр без SDK. В Telegram
оболочка ожидает непустые данные запуска, как в меню бота, inline-кнопке
и прямой ссылке на мини-приложение. Запуски из reply-клавиатуры и inline mode
могут передавать пустые данные. Настройка бота и запуск внутри iframe
браузерной версии Telegram относятся к отдельной приёмке. Чаты, постоплата,
платежи, чеки и подарок доступны в Web CityGo.
Для будущего пополнения внутри Telegram нужны
[Telegram Stars](https://core.telegram.org/bots/payments-stars#faq).

## MAX

`/mini/max` использует те же гостевые сценарии и
[цвета оболочки MAX из Figma](https://www.figma.com/design/xnlvdm113tfcHbZO5bekdg?node-id=4-94).
[MAX Bridge](https://dev.max.ru/docs/webapps/bridge) обрабатывает системную
кнопку «Назад» и открывает CityGo во внешнем браузере по нажатию. Данные
запуска служат подсказкой для выбора задачи. Обычный браузер открывает
гостевой экран без MAX Bridge. Привязка аккаунта, оплата и выдача подарка
внутри MAX относятся к следующим этапам.
