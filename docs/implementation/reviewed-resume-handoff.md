# Карьерный переход к черновику резюме

## Пользовательский маршрут

В открытом диалоге «Помощник по работе» раскройте «Ещё» под своим завершённым
сообщением и выберите «Подготовить резюме». Перед передачей видны только поля,
которые пользователь заполняет сам: цель, работодатель, фактическая должность,
выполненные задачи и навыки. Исходное сообщение можно открыть как подсказку.
Достаточно одной задачи. Открытые места остаются пустыми. Цель резюме хранится
отдельно от опыта и сама по себе не создаёт черновик.

«Остаться в разговоре» закрывает предпросмотр. «Перейти к помощнику по резюме»
открывает выбранный диалог и редактор «Черновик резюме». Текст состоит из явно
заполненных полей. Пользователь может исправить название и формулировки и
сохранить один результат явной кнопкой. Работодатель, фактическая должность и
навыки появляются только из сведений, введённых самим пользователем.

Черновик открывается из «Результаты → Открыть полностью». Повторное
редактирование и восстановление сохранённой версии доступны через «Мой план»
и «История изменений». При восстановлении используется действующая проверка
ревизии. Исходное сообщение о работе остаётся привязанным к результату. Пока сессия открыта, переход между вкладками сохраняет правки и идентификатор начатой операции сохранения.

## Связь с существующим кодом

Специализированный режим использует существующий диалог предпросмотра и
открытие авторизованного целевого диалога. Источник проверяется по владельцу,
сессии, выбранному диалогу и точному тексту завершённого пользовательского
сообщения. Получатель в этом переходе закреплён за помощником по резюме.
Совпадение владельца и точного целевого диалога проверяется до открытия
черновика. Подтверждённый текст используется в редакторе, без переноса в
обычное поле сообщения. Подготовка не запускает модель.

В «Результатах» используется существующий личный план. Его API подтверждает
владельца источника, поддерживает повтор с тем же ID операции и отдельные
ревизии. Для маршрута не нужны новые API-поля, миграции или права.
Сохранённые сведения и содержимое формы используют существующее скрытие от
записи Вебвизора. #119 добавляет общую память. #128 относится к проверке
сгенерированных моделью резюме. Этот маршрут опирается только на текущий main.

## Синтетическая приёмка

1. В своём сообщении о работе укажите пример задачи и отдельное требование из
   вымышленной вакансии. Откройте передачу. Все поля пустые, содержимое
   сообщения доступно только в свёрнутом источнике.
2. Введите одну выполненную задачу, исправьте её формулировку и перейдите к
   помощнику по резюме. В редакторе есть исправленный опыт. Пустые поля не
   появляются. Черновики обоих чатов остаются в своих диалогах.
3. Дополнительно отредактируйте черновик, сохраните и откройте результат
   полностью. Измените текст через «Мой план», восстановите первую версию из
   истории и проверьте результат после перезагрузки.
4. Повторите вход в предпросмотр и нажмите «Остаться в разговоре».
   Открытие диалога резюме, сохранение и отправка сообщения не выполняются.

Из открытого сохранённого резюме можно перейти к
[сравнению с выбранной вакансией и черновику отклика](reviewed-job-application.md).
