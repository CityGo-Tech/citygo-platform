# Обработка сообщений без предчатовой карточки

В Web и мобильной версии сайта больше нет карточки «Перед началом», дублирующей кнопки баланса, флажка и длинного текста под диалогом. Поле сообщения доступно до согласия; баланс, пополнение и телефон остаются в существующем личном кабинете.

При первой отправке без действующего согласия открывается короткое окно «Обработка сообщений». Полные условия текущего получателя доступны по раскрываемой ссылке. Только явное нажатие «Разрешить и отправить» сохраняет согласие и отправляет исходный вопрос. Отмена и Escape сохраняют черновик, не отправляя его помощнику. При последующих сообщениях окно не показывается, пока сервер считает согласие действующим.

Открытие окна само по себе не даёт согласия. Подтверждение привязано к пользователю, диалогу, версии условий и текущей сессии. Перед отправкой клиент проверяет результат сохранения через кабинет. Ошибка, смена пользователя, диалога или политики, а также отмена во время сохранения не разрешают автоматическую отправку. Изменившиеся условия требуют нового явного действия; автоматических повторов нет.

В разделе «Согласия» доступны статус, полные условия и отзыв согласия на обработку сообщений. История при отзыве сохраняется; новое сообщение снова потребует явного разрешения. Регистрационные согласия и серверная проверка AI-согласия остаются отдельными механизмами.

Серверный контракт, тексты политики, журнал согласий, схема БД и денежные расчёты этим изменением не меняются. Резерв 5 ₽ CityGo, фактическое списание ×10, оплата с чеками, подтверждение телефона и подарок 500 ₽ сохраняются. Выпуск на сервер и включение автодеплоя не входят в этот PR.
