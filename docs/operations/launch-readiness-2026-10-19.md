## Что подготовлено в рабочей ветке

- Допуск боевой оплаты с default closed, двумя режимами оператора, CAS и аудитом.
- API lifecycle сверки известных платежей/возвратов, DB lease и свежесть здоровья.
- Панель super admin и доступность пополнения, проверяемая сервером.
- Покупатель видит собственные сохранённые НПД-чеки; logout и поздние ответы
  не переносят их в чужую сессию. Email аккаунта не называется подтверждённым
  платёжным контактом.
- Новая миграция 22, минимальные grants, совместимость reset-инвентаря и
  обновлённые синтетические репетиции старых схем. Разрушительные reset-команды
  при работающих сервисах не выполнялись.
- Отдельная read-only проверка публичного каталога RouterAI. Она не читает
  `.env`/ключи, не отправляет промпты и не выполняется автоматически при старте API:

  ```sh
  node scripts/routerai-route-check.mjs --model deepseek/deepseek-v4-pro-0813 --upstream deepseek --country us --max-output-tokens 32768 --reasoning-effort high
  ```

  Exit 0 означает только совпадение с метаданными каталога, 2 — несовместимость,
  3 — непроверенный результат/ошибку чтения. Это не доказательство доступности
  генерации, места хранения, принятия точного reasoning effort или потолка цены.
  Переменные тарифы выводятся как отдельное предупреждение, не как резерв.

Подробный операторский процесс — [допуск оплаты](../runbooks/payment-admission.md).
Тариф прежний: пополнение 100 ₽ → 100 ₽ CityGo; независимая стоимость AI ×10;
неизвестные расходы не превращаются в бесплатный ответ. Подарок пока выключен.

## Что препятствует открытию

| Шаг                | Подтверждённое состояние                                                                   | Следующее действие                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------------- |
| Бесплатный CI      | Hyper-V включён; текущий процесс не имеет прав управлять ВМ. Runner не создан              | С владельцем предоставить управление отдельной ВМ; проверить изоляцию и только затем переводить workflow        |
| Выпуск             | Требуемые CI/release gates сохранены; рабочая ветка не является поставленным SHA           | Получить настоящие проверки, образы и свежие разрешения на закрытое 21→22                                       |
| RouterAI           | Публичный каталог у закреплённого DeepSeek endpoint показывает `cn`, текущий фильтр — `us` | Решение владельца о маршруте, новое точное уведомление и проверка стоимости/резерва; не менять получателя молча |
| Контрольный платёж | Разрешён один настоящий платёж 100 ₽ и полный возврат; ещё не выполнен                     | Владелец вводит карту; сверить начисление, повтор, возврат и НПД-обязательства                                  |
| Публичное открытие | Сервер остаётся закрытым                                                                   | После предыдущих пунктов отдельно проверить admission и открыть доступ                                          |

## Чего не делали

Не подключали оплату GitHub, не покупали подписку, не обходили release gate,
не копировали ключи в репозиторий/ВМ проверок, не меняли страну AI-провайдера,
не проводили реальный платёж или AI-запрос вместо владельца. Новая локальная
Linux-ВМ не подменена менее изолированным доступом runner к Windows/OneDrive/WSL.

Эти ограничения не мешают продолжать код и синтетические проверки, но результат
нельзя описывать как уже открытый сервис с проверенной боевой оплатой.
