## Что подготовлено в рабочей ветке

- Допуск боевой оплаты с default closed, двумя режимами оператора, CAS и аудитом.
- API lifecycle сверки известных платежей/возвратов, DB lease и свежесть здоровья.
- Панель super admin и доступность пополнения, проверяемая сервером.
- Покупатель видит собственные сохранённые НПД-чеки; logout и поздние ответы
  не переносят их в чужую сессию. Email аккаунта не называется подтверждённым
  платёжным контактом.
- Новая миграция 22, минимальные grants, совместимость reset-инвентаря и
  обновлённые синтетические репетиции старых схем. Разрушительные reset-команды
  при работающих сервисах не выполнялись.
- Отдельная read-only проверка публичного каталога RouterAI. Она не читает
  `.env`/ключи, не отправляет промпты и не выполняется автоматически при старте API:

  ```sh
  node scripts/routerai-route-check.mjs --model deepseek/deepseek-v4-pro-0813 --upstream deepseek --country cn --max-output-tokens 4096 --reasoning-effort high
  ```

  Exit 0 означает только совпадение с метаданными каталога, 2 — несовместимость,
  3 — непроверенный результат/ошибку чтения. Это не доказательство доступности
  генерации, места хранения, принятия точного reasoning effort или потолка цены.
  Переменные тарифы выводятся как отдельное предупреждение, не как резерв.

## Принятое решение об AI-маршруте

Первоначальное требование `ru` заменено явным решением владельца от 19 октября:
**DeepSeek Pro через RouterAI, `cn`, возможная обработка вне РФ; Flash запрещён.**
Это разрешение на маршрут, не согласие пользователей и не открытие сервера.
Публичная проверка в 04:43 МСК подтвердила exact
`deepseek/deepseek-v4-pro-0813` / upstream `deepseek` / `cn`, status 0, exit 0.
Ключи и inference не использовались; принятие именно reasoning `high` ещё не
подтверждено реальным запросом.

В ветке подготовлен отдельный [CN live-профиль v5](../runbooks/routerai-pro-cn-profile.md),
а не переопределён старый v4. Лимиты одной попытки — 8192 байта входа и 4096
токенов выхода. Четыре технические квоты в synthetic fixture нулевые. Прежние
`us`-настройки и approvals нельзя использовать для CN. Оба live-профиля закрыты
для standing autodeploy. На сервер новый профиль не установлен.

Дополнительно закрыт существовавший пробел ответа: при запросе exact Pro адаптер
теперь отвергает объявленные Flash/alias/чужую модель или отсутствие identity
до соответствующего текста. ID генерации сохраняется для сверки; повтора нет.
Это не доказательство фактического upstream и ещё не live-проверка совместимости.

Подготовлен [публичный кандидат уведомления](routerai-pro-cn-policy.candidate.json)
и его офлайн snapshot ID. Точный текст/ID ещё не одобрены для production;
они не подставляются автоматически. Смена получателя требует нового выбора
маршрута, budget execution rule и согласия пользователя.

По
[документации RouterAI](https://routerai.ru/docs/guides/overview/provider-selection)
фильтр использует `countries`; если расположение дата-центров не опубликовано,
метаданные могут отражать страну штаб-квартиры. Поэтому один код страны не
подтверждает всю цепочку обработки, хранение или соблюдение требований к данным.
Документация также предупреждает о резервных попытках вне `only`: уведомление
не обещает абсолютную эксклюзивность upstream.

Предложенный резерв — 6 ₽ реальных / 60 ₽ CityGo; он не записан в БД.
Peak-цены и reasoning/token-framing требуют отдельной приёмки. Это условная
оценка с запасом, не доказанный внешний hard cap и не фиксированная цена ответа.

Подробный операторский процесс — [допуск оплаты](../runbooks/payment-admission.md).
Тариф прежний: пополнение 100 ₽ → 100 ₽ CityGo; независимая стоимость AI ×10;
неизвестные расходы не превращаются в бесплатный ответ. Подарок пока выключен.

## Что препятствует открытию

| Шаг                | Подтверждённое состояние                                                                    | Следующее действие                                                                                       |
| ------------------ | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| Бесплатный CI      | Hyper-V включён; текущий процесс не имеет прав управлять ВМ. Runner не создан               | С владельцем предоставить управление отдельной ВМ; проверить изоляцию и только затем переводить workflow |
| Выпуск             | Требуемые CI/release gates сохранены; рабочая ветка не является поставленным SHA            | Получить настоящие проверки, образы и свежие разрешения на закрытое 21→22                                |
| RouterAI           | Принят Pro/deepseek/cn; отдельный v5 и кандидат уведомления подготовлены, но не установлены | Утвердить полный snapshot; закрыто проверить цену/резерв и exact новую цепочку выпуска                   |
| Контрольный платёж | Разрешён один настоящий платёж 100 ₽ и полный возврат; ещё не выполнен                      | Владелец вводит карту; сверить начисление, повтор, возврат и НПД-обязательства                           |
| Публичное открытие | Сервер остаётся закрытым                                                                    | После предыдущих пунктов отдельно проверить admission и открыть доступ                                   |

## Чего не делали

Не подключали оплату GitHub, не покупали подписку, не обходили release gate,
не копировали ключи в репозиторий/ВМ проверок, не меняли страну в рабочем runtime,
не проводили реальный платёж или AI-запрос вместо владельца. Новая локальная
Linux-ВМ не подменена менее изолированным доступом runner к Windows/OneDrive/WSL.

Эти ограничения не мешают продолжать код и синтетические проверки, но результат
нельзя описывать как уже открытый сервис с проверенной боевой оплатой.
