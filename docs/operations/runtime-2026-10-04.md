## Особенность доступа S3

Чтение versioning/lifecycle настроек бакета возвращало `AccessDenied` из-за
ограничений IAM. Это не следует путать с отказом Get/Put/Delete объектов.
Контроллер проверяет `VersionId` через HeadObject и отказывается удалять
версионные объекты; подробности — [retention](../runbooks/hourly-backup-retention.md).
Административные права S3 ради этой проверки не выдавались.

## Что не проверялось

- Новый restore drill, восстановление вне основной ВМ и фактические RPO/RTO.
- Живой ответ нейросети, активная модель, текущие денежные лимиты и расходы.
- Нагрузочная ёмкость для 20 пользователей и полный продуктовый сценарий R1.
- Доставка нового email, внешнее обнаружение полного отключения ВМ.
- Срок действия всех credentials и возможность аварийного входа в консоль.

Успешная readiness и свежий архив не заменяют эти проверки. Ключи, полные
конфиги, дампы, SSH host keys, IP ВМ и сведения об аккаунтах в этот документ
не включены. Для повторной безопасной проверки используйте
[руководство оператора](server-handbook.md#5-проверка-состояния-без-изменения-данных).
