# GPT-6 Astra через RouterAI — профиль качества

Профиль подготовлен 14 сентября 2026 по запросу владельца CityGo. Прямой OpenAI
остаётся отдельным подключением, его модель, ключ и значения по умолчанию не меняются.
Старые истории Qwen не переименовываются. Переключение провайдера не сбрасывает
использованные попытки, денежные резервы или согласия.

## Настройки

Задавайте эти значения только в серверном окружении локального стенда:

```dotenv
LLM_PROVIDER=routerai
ROUTERAI_MODEL=openai/gpt-6-astra
ROUTERAI_UPSTREAM=openai
ROUTERAI_COUNTRY=us
ROUTERAI_REASONING_EFFORT=high
ROUTERAI_MAX_OUTPUT_TOKENS=32768
ROUTERAI_REQUEST_TIMEOUT_MS=240000
LLM_MAX_INPUT_BYTES=64000
```

Ключ RouterAI хранится отдельно; не вставляйте его в этот файл, чат, PR или Web.
Существующие `OPENAI_API_KEY` и `OPENAI_MODEL` оставьте без изменений.
`high` выбран как отправная настройка для сложных рекомендаций. Больший уровень
рассуждений сам по себе не гарантирует более качественный результат: проверяйте
корректность, полезность и русский язык на сценариях CityGo.

Для точного идентификатора Astra адаптер отправляет `reasoning_effort` и
`max_completion_tokens`, не `max_tokens`. Общий лимит 32768 включает рассуждения
и финальный ответ; это запас для генерации, не требование писать длинно. Температура,
top_p, инструменты и поиск не включаются. Автоматического перехода на Qwen, другого
провайдера или прямой OpenAI при ошибке нет.

Переопределения действуют по фактически выбранному в Admin провайдеру, а не только
по первоначальному `LLM_PROVIDER`. В отсутствие переопределений остаются прежние
1400 токенов и 60 секунд. Для длинного ожидания срок занятости чата увеличивается
вместе с серверным сроком, с запасом 30 секунд; сетевой запрос не удерживает
транзакцию базы.

## Применение и деньги

1. Соберите обновлённые общие пакеты и API, перезапустите только нужный стенд.
2. В Admin заново подтвердите RouterAI с моделью Astra: сохранённая политика Qwen
   намеренно не совпадает с новой. До подтверждения AI может быть «не настроен».
3. После изменения выходного лимита нужен новый денежный допуск для нового ключа
   исполнения. Старые правила не переносятся автоматически и не обнуляются.
4. Согласие пользователя на нового получателя/модель подтверждается отдельно.
   Административный выбор не выдаёт его автоматически.
5. Выполните согласованный тест с вымышленными данными: русский ответ, поток,
   история, передача специалисту, завершение квеста и +60 XP. Сверьте usage,
   возвращённую модель и фактическое списание с журналом RouterAI.

Фраза «качество важнее стоимости» означает свободный профиль, но не бесконечный
бюджет. Сумму живого теста согласуйте отдельно. Локальная сумма резервов не является
счётом провайдера. Учитывайте reasoning, кеш, изменения цен и все допустимые маршруты.
Предыдущий остановленный Qwen-пилот нельзя перезапускать удалением его маркеров.

Текущий локальный подготовительный стенд по-прежнему блокирует модельную сеть и
имеет выключенный бюджет. Выбор Astra в нём не списывает деньги и не подтверждает
доступность модели по ключу. Production-блокировка RouterAI не снимается.

## Проверка источников и границы достоверности

- [OpenAI: GPT-6 Astra](https://developers.openai.com/api/docs/models/gpt-6-astra)
  подтверждает модель и допустимые уровни рассуждений.
- [OpenAI: переход на Astra](https://developers.openai.com/api/docs/guides/latest-model)
  подтверждает текстовый Chat Completions; вызов инструментов требует Responses.
- [RouterAI: точная модель](https://routerai.ru/models/openai/gpt-6-astra)
  публикует идентификатор, Chat Completions и цены.
- [RouterAI: параметры](https://routerai.ru/docs/guides/overview/parameters) описывает
  `max_completion_tokens`; [управление reasoning](https://routerai.ru/pages/gpt-claude-gemini-api)
  документирует нативный `reasoning_effort` для OpenAI.
- [RouterAI: маршруты Astra](https://routerai.ru/api/v1/models/openai/gpt-6-astra/endpoints)
  на дату проверки содержит OpenAI, Flex, Priority и Azure, но `supported_apis`
  пуст, а наборы параметров отличаются. Это несогласованность метаданных; офлайн-
  тесты не заменяют проверку реального шлюза и фактического полного лимита.

По тарифу Standard на дату проверки 1000 входных токенов стоят около 1,10 ₽,
1000 выходных (включая reasoning) — 5,48 ₽, без дополнительных кеш-начислений.
Источник — каталог RouterAI выше; это не фиксированная цена и не оценка каждого
сообщения. Живые ответы Astra в рамках подготовки не запрашивались.
