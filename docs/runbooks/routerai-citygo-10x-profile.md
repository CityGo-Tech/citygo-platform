# Production профиль CityGo с тарифом 10 к 1

Профиль `citygo-api-web-routerai-citygo-10x-v1` закрепляет списание с баланса
CityGo в десятикратном размере подтверждённой стоимости RouterAI. Расход
оператора 1 ₽ соответствует списанию 10 ₽ CityGo. Пополнение по принятому
правилу остаётся 1:1: платёж 100 ₽ должен начислять 100 ₽ CityGo, не 1000 ₽.

**В этом профиле ЮKassa выключена.** Боевой транспорт ещё не реализован;
тестовый магазин разрешён только в отдельной непродукционной БД с выключенным
AI. Sandbox-пополнение нельзя использовать для финансирования реальных моделей.
Наличие профиля не разрешает расходы, открытие сервиса или передачу данных.

## Выбор профиля

| Профиль контроллера                     | Startup approval | Маркер API               | Тариф                      | ЮKassa          |
| --------------------------------------- | ---------------- | ------------------------ | -------------------------- | --------------- |
| `citygo-api-web-disabled-v1`            | v1               | отсутствует              | AI выключен                | выключена       |
| `citygo-api-web-routerai-credit-v1`     | v2               | `routerai-credit-v1`     | прежний `routerai_at_cost` | выключена       |
| `citygo-api-web-routerai-citygo-10x-v1` | v3               | `routerai-citygo-10x-v1` | `routerai_citygo_10x`      | явно `disabled` |

Старый профиль v2 не изменён на ×10. Секрет одного тарифа не принимается
под маркером другого; approval v1/v2 не разрешает новый профиль.

## Защищённая конфигурация API

Создать отдельный API JSON вне Git, release bundle и работающего mount.
Все поля обязательны, значения — строки без внешних пробелов и управляющих
символов. Размер файла не более 16 KiB, неизвестные поля запрещены.

| Поле                                                               | Значение                                                                                                                      |
| ------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| `DATABASE_URL`                                                     | Секрет роли `citygo_api`, `postgres:5432`, БД `citygo_pilot`, без query/fragment                                              |
| `ADMIN_USER_IDS`                                                   | От 1 до 20 различных положительных числовых ID через запятую без пробелов; совместимость конфигурации, **не** назначение роли |
| `ROUTERAI_API_KEY`                                                 | Реальный ключ только в защищённом API JSON, до 8192 символов                                                                  |
| `ROUTERAI_DATA_NOTICE`                                             | Независимо утверждённый публичный текст, до 4000 UTF-16 единиц                                                                |
| `ROUTERAI_PRODUCTION_POLICY_ID`                                    | Независимо утверждённый hash точного публичного snapshot, 64 lowercase hex                                                    |
| `AI_CREDIT_MODE`                                                   | `routerai_citygo_10x`                                                                                                         |
| `YOOKASSA_MODE`                                                    | `disabled`                                                                                                                    |
| `ROUTERAI_MODEL`                                                   | `deepseek/deepseek-v4-pro-0813`                                                                                               |
| `ROUTERAI_UPSTREAM`                                                | `deepseek`                                                                                                                    |
| `ROUTERAI_COUNTRY`                                                 | `us`; метаданные маршрута, не гарантия региона хранения                                                                       |
| `ROUTERAI_REASONING_EFFORT`                                        | `high`                                                                                                                        |
| `ROUTERAI_MAX_OUTPUT_TOKENS`                                       | `32768`                                                                                                                       |
| `ROUTERAI_REQUEST_TIMEOUT_MS`                                      | `240000`                                                                                                                      |
| `LLM_MAX_INPUT_BYTES`                                              | `64000`                                                                                                                       |
| `LLM_USER_DAILY_REQUEST_LIMIT`, `LLM_USER_DAILY_ATTEMPT_LIMIT`     | Явно выбранные целые от 0 до 10000                                                                                            |
| `LLM_GLOBAL_DAILY_REQUEST_LIMIT`, `LLM_GLOBAL_DAILY_ATTEMPT_LIMIT` | Явно выбранные целые от 0 до 1000000                                                                                          |

Счётчики запросов/попыток — технические ограничения, не суточный денежный лимит
пользователя. Общий бюджет оператора и потолок одной попытки задаются отдельно
в Admin. Профиль их не включает и не начисляет баланс.

`YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY`, любые другие платёжные поля,
OpenAI/GigaChat credentials и произвольные endpoint/fallback запрещены в этом
JSON. Переменные `YOOKASSA_*`, `AI_CREDIT_MODE` и настройки провайдеров также
нельзя добавлять в ambient environment: единственный источник — одобренный mount.
Контроллер передаёт только маркер и `LLM_PROVIDER=routerai`; секрет доступен
только API, не Web, Worker, мигратору или backup.

`deploy/fixtures/routerai-citygo-10x-profile.fixture.json` содержит вымышленные
ключ, пароль и policy ID. Это тестовая фикстура, **не** конфигурация сервера.
Реальный public policy preview проверяется до остановки приложения; нельзя
автоматически одобрить ID, вычисленный из неизвестных настроек.

## Закрытый выпуск

Следовать [плану перехода 12 → 18](../operations/closed-upgrade-12-to-18.md)
и [операторскому CLI](release-operator.md). Startup approval имеет `version: 3`,
точное имя нового профиля, hash новых байтов API JSON и hash migration approval;
`allow_start:true`, `allow_traffic:false`. Отдельные approvals preparation,
migration и finish остаются обязательными.

Контроллер запускает неизменяемые образы в production, проверяет readiness
и неавторизованные маршруты. Health не регистрирует пользователей и не вызывает
модели/оплату. Finish и commit recovery сохраняют профиль и hash mount, но не
открывают ingress, Worker или restart. Первую установку нельзя проводить через
`autodeploy.apply`: его последующая фаза resume предназначена для открытия.

Роли администратора хранятся в БД. `ADMIN_USER_IDS` не выдаёт административных
прав. Чистый запуск/закрытое создание первого super admin и обязательная смена
его временного пароля — отдельная операция по [инструкции](fresh-test-launch.md).

## Баланс и оплата до открытия пилота

Новый пользователь получает нулевой баланс. Подарок 500 ₽ CityGo закрыт до
подключения подтверждения телефона. По тарифу 500 ₽ CityGo соответствуют 50 ₽
подтверждённой себестоимости; внешние расходы контролируются резервами и
потолками попыток. Телефон сам по себе не доказывает уникальность человека. Ручной welcome endpoint
в режиме ×10 возвращает 503, в том числе администратору.

Live-пополнение и live-возвраты требуют отдельной реализации и приёмки:

- Новый transport и **новая** миграция: применённая `0015` намеренно допускает
  только тестовые заказы и не редактируется ради live.
- Серверная проверка магазина/суммы/валюты/идемпотентности, долговечная обработка
  уведомлений и повторная сверка неоднозначных платежей/возвратов.
- Принятый ручной процесс НПД: оформление, передача покупателю и корректировки
  при возвратах. Реестр уже есть, но не формирует/не отправляет чеки автоматически.
- Реальные credentials через защищённый ввод, отдельный согласованный live-тест
  и разрешение принимать деньги. Новый многоразовый счёт не нужен.

До этого момента не переносить тестовые средства в рабочую БД, не снимать
платёжный карантин и не выдавать статус «готов к оплате». Подробности:
[подготовка ЮKassa](yookassa-live-preparation.md), [НПД](manual-npd-receipts.md),
[оплаченные лоты и возвраты](paid-lots-and-refunds.md).
