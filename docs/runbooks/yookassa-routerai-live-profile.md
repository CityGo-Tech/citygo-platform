# Закрытый runtime профиль ЮKassa и RouterAI

Это исторический профиль **v4** с `country=us`. Решение владельца от 19 октября
реализуется отдельным [CN-профилем v5](routerai-pro-cn-profile.md). Не менять
значения v4 и не переиспользовать его разрешения для нового маршрута.

Профиль `citygo-api-web-routerai-citygo-10x-yookassa-live-v1` позволяет закрыто
запустить production API с боевым транспортом ЮKassa и тарифом CityGo ×10.
Он требует startup approval **v4** и отдельного выпуска
[18 → 21](../operations/closed-upgrade-18-to-21.md). Доступ остаётся закрыт,
Worker остановлен, restart выключен. Профиль не разрешает принимать деньги,
вызывать модели или открывать сайт.

Старые профили v1–v3 не расширены: v3 по-прежнему требует
`YOOKASSA_MODE=disabled` и отвергает платёжные ключи. Standing autodeploy
намеренно отвергает новый профиль: его этап resume открывает доступ и не подходит
для этого закрытого выпуска.

## Точный состав API конфига

API JSON хранится в отдельном защищённом каталоге вне Git, bundle и текущего
mount. Все значения — непустые строки без внешних пробелов и управляющих
символов. Лимит всего файла 16 KiB; неизвестные и пропущенные поля запрещены.

| Поля                                                               | Значения                                                                                                           |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------ |
| `DATABASE_URL`                                                     | Существующая роль `citygo_api`, `postgres:5432/citygo_pilot`, без query и fragment                                 |
| `ADMIN_USER_IDS`                                                   | 1–20 различных положительных числовых ID; это не назначение роли                                                   |
| `ROUTERAI_API_KEY`                                                 | Боевой ключ, только в API mount, не более 8192 символов                                                            |
| `ROUTERAI_DATA_NOTICE`, `ROUTERAI_PRODUCTION_POLICY_ID`            | Отдельно утверждённые текст и hash точного публичного snapshot; текст до 4000 UTF-16 единиц, hash 64 lowercase hex |
| `AI_CREDIT_MODE`                                                   | `routerai_citygo_10x`                                                                                              |
| `YOOKASSA_MODE`, `YOOKASSA_RECEIPT_MODE`                           | `live`, `npd_manual`                                                                                               |
| `YOOKASSA_SHOP_ID`                                                 | Проверенный ID существующего обычного магазина: 1–20 цифр, без ведущего нуля                                       |
| `YOOKASSA_SECRET_KEY`                                              | Боевой ключ; предохранитель приложения `live_` + 8–8192 символа из `A–Z a–z 0–9 _ = -`; test-ключ запрещён         |
| `ROUTERAI_MODEL`, `ROUTERAI_UPSTREAM`, `ROUTERAI_COUNTRY`          | `deepseek/deepseek-v4-pro-0813`, `deepseek`, `us`                                                                  |
| `ROUTERAI_REASONING_EFFORT`, `ROUTERAI_MAX_OUTPUT_TOKENS`          | `high`, `32768`                                                                                                    |
| `ROUTERAI_REQUEST_TIMEOUT_MS`, `LLM_MAX_INPUT_BYTES`               | `240000`, `64000`                                                                                                  |
| `LLM_USER_DAILY_REQUEST_LIMIT`, `LLM_USER_DAILY_ATTEMPT_LIMIT`     | Целые строки 0–10000; начальный закрытый конфиг — **`0`**                                                          |
| `LLM_GLOBAL_DAILY_REQUEST_LIMIT`, `LLM_GLOBAL_DAILY_ATTEMPT_LIMIT` | Целые строки 0–1000000; начальный закрытый конфиг — **`0`**                                                        |

`WEB_ORIGIN` не хранится в секрете: канонический HTTPS origin поступает из
проверенного release request и закрепляется разрешениями. Произвольные endpoint,
return URL, fallback и OpenAI/GigaChat credentials запрещены. Страна `us` описывает
маршрут, а не доказанное место хранения данных.

Контроллер передаёт в environment только `LLM_PROVIDER=routerai` и маркер
`CITYGO_AI_PROFILE=routerai-citygo-10x-yookassa-live-v1`. Сам JSON монтируется
только в API. Web, Worker, мигратор и backup не получают ключи. Ambient
`YOOKASSA_*`, `ROUTERAI_*`, `AI_CREDIT_MODE` и второй источник тех же значений
останавливают профиль. Hash startup approval закрепляет **весь** JSON, включая
магазин, ключи, текст политики и технические квоты.

Файл `deploy/fixtures/routerai-citygo-10x-yookassa-live-profile.fixture.json`
содержит только неработающие вымышленные значения для тестов. Его нельзя
переносить на сервер как реальные настройки.

## Подготовка секретов

1. Сохранить ключ существующего обычного магазина через закрытый ввод вне Git.
   Читать значения только внутри помощника переноса; не печатать JSON, ключи,
   заголовки Authorization и результаты credential API в чат или журнал.
2. До остановки сервисов отдельно проверить магазин read-only запросом
   `GET https://api.yookassa.ru/v3/me`: точное совпадение ID, `test=false`,
   статус enabled и доступные способы оплаты. Это проверка credentials, а не
   подтверждение договора, чеков или денежного процесса.
3. Собрать новый конфиг рядом с текущим, без перезаписи текущего mount. Сохранить
   прежний DATABASE_URL, утверждённый snapshot RouterAI и четыре нулевые квоты.
   Не вычислять новое согласие автоматически из неизвестного конфига.
4. Проверить его новым отдельно проверенным контроллером, зафиксировать только
   путь/hash/имена полей в закрытой операторской записи. Не выдавать разрешения
   до готовности точного опубликованного target и проверенных образов.

Состояние на подготовительном этапе: ключ ЮKassa локально проверен read-only;
новый JSON и новый контроллер этим PR **не устанавливаются на ВМ**. Windows
хранилище ключа закрыто ACL текущего пользователя и SYSTEM, но не зашифровано.
Не путать сохранённый ключ с подготовленным серверным mount.

## Деньги и условия открытия

Платёж 100 ₽ начисляет 100 ₽ CityGo. Подтверждённая себестоимость AI 1 ₽
списывает 10 ₽ CityGo. Сначала расходуется подарок, затем оплаченные лоты FIFO;
500 ₽ подарка остаются выключены до подключения подтверждения телефона.

Миграция 0020 сама не включает расходы и сохраняет существующие лимиты.
После закрытого выпуска режим `routerai_balance` включается отдельной
административной командой с текущей revision, проверенными execution rules,
потолком одной попытки и явными `null` общего, суточного и пользовательского
денежных лимитов. Баланс пользователя, резерв, ×10 и технические квоты сохраняются.
Это не запрос баланса RouterAI: провайдер прекращает обслуживание при исчерпании
предоплаты; HTTP 402 не вызывает повтор или fallback. Неизвестная стоимость уже
отправленной попытки остаётся на сверке.

До открытия нужны отдельная приёмка оплаты/возвратов, ручного
[реестра НПД](manual-npd-receipts.md), регулярной сверки очереди и её сбоев,
а также разрешение на публичный доступ и реальные расходы. Профиль не отправляет
чеки в ФНС и не доставляет их покупателю. Sandbox-деньги нельзя смешивать
с real-AI БД; защитные флаги не сбрасываются при этом обновлении.
