# RouterAI + DeepSeek Pro — основной профиль CityGo

По запросу владельца от 21 сентября 2026 вместо GPT-6 Astra выбран
**DeepSeek V4 Pro 0813**. Прямой OpenAI и GigaChat остаются независимыми
подключениями: их ключи, модели и настройки не удаляются.

## Серверные настройки

```dotenv
LLM_PROVIDER=routerai
ROUTERAI_MODEL=deepseek/deepseek-v4-pro-0813
ROUTERAI_UPSTREAM=deepseek
ROUTERAI_COUNTRY=us
ROUTERAI_REASONING_EFFORT=high
ROUTERAI_MAX_OUTPUT_TOKENS=32768
ROUTERAI_REQUEST_TIMEOUT_MS=240000
LLM_MAX_INPUT_BYTES=64000
```

Это явный профиль для существующего локального стенда, не автоматическое
включение AI в чистом клоне. Ключ RouterAI передаётся только API из хранилища
секретов. Не записывайте ключи в этот документ, Git, браузер или чат.

Точная версия закреплена без `latest`-алиаса. В каталоге RouterAI для поставщика
`deepseek` указан фильтр `us`; это метаданные маршрута, не гарантия страны
обработки или хранения данных. Другие поставщики и автоматический fallback
отключены (`provider.only=["deepseek"]`, `allow_fallbacks=false`).

Запрос использует `max_tokens` и `reasoning: { effort: "high" }`, а не нативные
поля Astra `max_completion_tokens` / `reasoning_effort`. Сохраняется профиль
качества: до 32768 выходных токенов, 240 секунд, 128000 символов видимого ответа
и 16 MiB потока. Рассуждения не выдаются в чат. Это верхние пределы, не требование
писать длинно; фактическое качество и поддержку параметров проверяют живым тестом.

## Применение к существующей базе

1. Собрать общие пакеты и перезапустить целевой локальный API с этим профилем.
2. В `/admin` подтвердить **RouterAI / deepseek/deepseek-v4-pro-0813**.
   Одного `LLM_PROVIDER` недостаточно: база сохраняет выбор и идентификатор
   политики модели/получателя. API переключения проверяет ревизию и пишет аудит.
3. Не переносить согласия Astra на нового получателя: пользователь подтверждает
   новую политику отдельно перед отправкой своих данных.
4. Сохранить историю, использованные попытки, денежные резервы и настроенные
   лимиты. Переключение не меняет бюджет и не включает расходы. Первоначальный
   суточный ориентир 500 ₽ заменён решением владельца от 27 сентября:
   **разовый бонус 500 ₽**, без ежедневного восстановления. Личный баланс и
   общий бюджет — разные механизмы; [актуальный учёт](ai-credit-charging.md).
   Для новой модели нужен отдельный денежный допуск, привязанный к её execution ID;
   старый допуск Astra не подходит. Перед включением проверьте текущие тарифы:
   для верхней оценки учитывайте самый дорогой разрешённый период, reasoning,
   полный контекст и запас. Тариф не зашивается в код.
5. Проверка выбора через административный API не вызывает модель. Живой тест
   проводится отдельно с вымышленными данными и согласованным пределом расходов.

Исторический подготовительный стенд запускался с выключенным бюджетом и без
модельной сети. Этот отчёт не описывает сегодняшнее состояние сервера.
Выбор DeepSeek не означает успешного живого ответа. Production-блокировка
GigaChat сохраняется; для RouterAI добавлен отдельный
[точный production-допуск](routerai-production.md), выключенный по умолчанию.
Архивные пилоты OpenAI/Qwen/Astra не перезапускаются.
