# Режимы ответа помощников

Пользователь выбирает «Максимум», «Баланс» или «Минимум» в текущем диалоге.
Начальный выбор — «Баланс». Переключение не отправляет запрос, не создаёт чат и
не списывает деньги. Во время ответа и обновления истории выбор заблокирован.
При ошибке текст сохраняется без автоматического повтора.

## Серверные маршруты

| Режим    | Модель                          | Подключение                                                 |
| -------- | ------------------------------- | ----------------------------------------------------------- |
| Максимум | `openai/gpt-6.1-sol`            | RouterAI Responses, upstream `openai`, фильтр `us`          |
| Баланс   | `deepseek/deepseek-v4-pro-0813` | RouterAI Chat Completions, upstream `deepseek`, фильтр `cn` |
| Минимум  | Настроенная модель GigaChat     | Прямой API GigaChat                                         |

Браузер не задаёт модель, URL, upstream или credentials. Обычный интерфейс получает
три названия и доступность. Подмены режима при сбое нет. Два RouterAI-маршрута
используют один существующий `ROUTERAI_API_KEY`.

Каталог RouterAI 26 октября 2026 года указывает `responses` для точного GPT endpoint
`openai` и `chat` для DeepSeek. Responses-обработчик проверяет идентификатор,
модель, терминальное `response.completed`, текст и usage; reasoning не выводится.
HTTP 200, частичный текст и обрыв потока не подтверждают завершение.

Первый контрольный запрос остановил диагностический скрипт: он ошибочно не
принимал штатный префикс `rai-`. В отдельной повторной проверке исправленным
скриптом выполнен один новый синтетический запрос без пользовательской истории.
HTTP 200 и одинаковые идентификаторы заголовка/потока подтверждены; модель внутри
потока отличалась от ожидаемого имени, после отмены квитанция не называла
получателя. Отдельная ограниченная диагностика с дочитыванием потока установила:
RouterAI возвращает точное native-имя `gpt-6.1-sol` вместо полного идентификатора.
Получены завершённый ответ, usage и строгая квитанция с `openai`, исходным полным
идентификатором, session reference и стоимостью `0.01172634736 RUB`.

Обработчик поддерживает только эту явную пару имён для данного Responses-маршрута;
другие модели, датированные версии, пустое имя и изменение имени внутри потока
не принимаются. Запрос и квитанция сохраняют полный идентификатор. Диагностическое
дочитывание само по себе не является проверкой генерации обработчиком приложения.
Отдельный контроль адаптера точного коммита `0b879a5` завершился успешно:
одна синтетическая генерация, завершённый ответ и строгая рублёвая квитанция.
Этот результат не проверяет будущий серверный конфиг или списание с аккаунта.
Автоматических повторных генераций нет; проверки со смоделированными ответами
не заменяют контроль провайдера.

Источники: [GPT](https://routerai.ru/models/openai/gpt-6.1-sol),
[DeepSeek](https://routerai.ru/models/deepseek/deepseek-v4-pro-0813),
[маршрутизация](https://routerai.ru/docs/guides/overview/provider-selection).
Каталожная цена не заменяет фактическую квитанцию запроса. Страна может обозначать
штаб-квартиру и не доказывает место хранения данных.

## Готовность прямого GigaChat

Два платных RouterAI-профиля реализованы; их наличие не заменяет успешную
контрольную генерацию и проверку стоимости. Для GigaChat готовится отдельный
режим с существующим ключом `GigaChat-3-Ultra` / `GIGACHAT_API_PERS`: бесплатное
использование провайдера и фиксированная плата CityGo **3 ₽ за успешный ответ**.
Это отдельный тариф сервиса. Нулевую стоимость провайдера и число токенов нельзя
выдавать за подтверждённую рублёвую квитанцию RouterAI или применять к ним ×10.

Настройка — `GigaChat-3-Ultra`, `GIGACHAT_API_PERS`. Read-only проверка существующего
ключа прошла: авторизация, список моделей и остаток токенов доступны. Генерации
не выполнялись. API не называет тариф и не подтверждает рублёвую стоимость.
По документации GigaChat на 26 октября 2026 года Ultra доступен только в
Freemium, а Freemium предназначен для личного некоммерческого использования.
Остаток бесплатных токенов не разрешает включить этот проект в публичном CityGo.
Нужен подтверждённый коммерческий доступ и доступная в нём модель; другую модель
или пакет нельзя молча считать тарифом Ultra.

Источники: [доступность Ultra](https://developers.sber.ru/docs/ru/gigachat/models/gigachat-3-ultra),
[коммерческое использование](https://developers.sber.ru/docs/ru/gigachat/tariffs/commercial),
[условия Freemium, п. 2.4](https://developers.sber.ru/docs/ru/policies/gigachat-agreement/individuals).

Новая настройка по умолчанию выключена. Прежний строгий runtime-профиль v12
не получает GigaChat credentials или разрешение его включить. Нужны отдельные
проверка условий аккаунта и разрешение выпуска. Настройка бюджета
`routerai_balance` сохраняет прежнюю роль для платных RouterAI-запросов;
GigaChat не маскируется под этот маршрут или его стоимость.

## Фиксация выбора и деньги

Миграция `0033_ai_request_modes.sql` сохраняет неизменяемый профиль принятого
запроса: режим, каталог, согласие, маршрут и execution key. Ключ также связывает
протокол, reasoning, тайм-аут и ограничения запроса. Следующее переключение не
меняет принятый профиль. Повтор request ID не создаёт новую попытку. SQL-guard
дополнительно запрещает попытке отклониться от сохранённого профиля.

Общий `ai_routing` остаётся административным выключателем. Пользовательский выбор
не меняет его или другие аккаунты. Согласие регистрации связывается с новым
набором получателей; старое согласие не расширяется автоматически.

Резерв — 5 ₽ CityGo. Для RouterAI списание — подтверждённая фактическая стоимость
×10; остаток резерва освобождается. Проверяются generation ID, session reference,
модель, upstream, API и источник. Сверка использует исходный профиль запроса.
Неизвестная стоимость сохраняет резерв и блокирует новый платный запрос, включая
другой режим. Для «Минимума» после подтверждённого успешного ответа списывается
ровно **3 ₽ CityGo**, оставшиеся **2 ₽** резерва освобождаются. Ошибка или
незавершённый ответ не считаются успешной платной услугой. Этот фиксированный
тариф не меняет ×10 и фактические квитанции двух RouterAI-режимов.

Схема **34** добавляет `gigachat_request_fees` и `gigachat_account_leases`:
отдельные доказательства фиксированного списания и общую для реплик аренду
аккаунта провайдера. Они входят в резервные снимки и сохраняются при обслуживании;
наличие записей блокирует прежние тестовые сбросы и обратные учебные миграции.
Платежи, чеки, телефон, подарок 500 ₽ и автодеплой не переключаются.

Один аккаунт PERS допускает один запрос CityGo одновременно, включая разные
аккаунты пользователей и реплики API с общей БД. Запросы с тем же ключом вне
CityGo эта аренда не контролирует. Смена секрета того же Client ID не создаёт
новую очередь. Перед заменой самого аккаунта провайдера или выключением флага
тарифа нужно завершить либо восстановить его незавершённые резервы. Общий
административный стоп AI запрещает новые попытки без потери истории расчётов.

## Закрытое включение

`AI_ASSISTANT_MODES=disabled` сохраняет прежний одиночный маршрут. Новый строгий
runtime-профиль заканчивается на `prostosms-unlimited-assistant-modes-v1` и
подготавливает два RouterAI-маршрута, сохраняя production-блокировку GigaChat.
Разработка фиксированного тарифа «Минимума» не расширяет этот профиль автоматически.

Отдельный профиль v13 с окончанием
`prostosms-unlimited-assistant-modes-gigachat-flat3-v1` подготавливает три режима.
Он сохраняет значения v12 для RouterAI, оплаты, чеков, почты и телефона и отдельно
закрепляет `AI_MINIMUM_FIXED_FEE=enabled`, `GigaChat-3-Ultra`,
`GIGACHAT_API_PERS` и тайм-аут 60 секунд. Только этот профиль принимает
`GIGACHAT_CREDENTIALS` в закрытом API-конфиге. Версия и хеш всего конфига входят
в отдельное разрешение закрытого запуска. Выбор нового профиля сам по себе
не открывает сайт, AI-бюджет, маршрутизацию или выдачу подарков.

Публичный сертификат GigaChat включён только в API-образ по закреплённому пути.
Сборка и новый профиль проверяют точные байты, отпечаток, признак CA, самоподпись
и срок. Он применяется только существующим HTTPS-транспортом GigaChat; глобальное
доверие не меняется. Сертификата нет в образах Web и Jobs. [Источник и обновление](../../deploy/certificates/README.md).
Смена пути, дополнительный ключ, другой тариф или модель требуют нового профиля,
а не переменной среды поверх старого разрешения.

Схема остаётся **34**: для этого профиля новых миграций и SQL-прав нет.
Порядок подготовки выпуска — [отдельный контрольный список](assistant-modes-release.md).

API-only настройки: `AI_ASSISTANT_MODES`, `AI_MODES_DATA_NOTICE`,
`AI_MODES_PRODUCTION_POLICY_ID`, `AI_MAXIMUM_REASONING_EFFORT` и
`AI_MINIMUM_FIXED_FEE`. Последний флаг по умолчанию `disabled`; `enabled`
допускается только с точным профилем Ultra/PERS, тарифом ×10 и резервом 5 ₽.
Фиксированная плата входит в execution key, а общая аренда привязана к аккаунту
GigaChat и сохраняется при смене его секрета. Настройки не попадают в
Web, Mobile и сборку. `preview-policy` рассчитывает снимок набора без БД, ключей и
AI-запросов. Старый `ROUTERAI_PRODUCTION_POLICY_ID` сохраняется для bootstrap.

На существующей БД `initializeAiRouting` не меняет действующий маршрут. После
копии и закрытого обновления оператор отдельно подтверждает routing нового
набора и точные execution rules бюджета. Наличие ключа или флага не разрешает
расходы и не добавляет согласия пользователей.

Работа следует за PR #123 и схемой 32. Слияние, публикация и обновление сервера
выполняются отдельно. Автодеплой остаётся выключенным.
