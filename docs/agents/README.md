# Agent architecture

Agents are versioned software modules inside the monorepo, not repositories or
microservices. The orchestrator routes using the message, active quest, profile,
target city, budget, and completed actions.

Each agent defines role, prompt version, tool allowlist, response contract,
knowledge scope, eval dialogues, safety boundaries, human handoff, and UI
metadata. Legal/Documents remains deferred until a verified source and review
process exists.
