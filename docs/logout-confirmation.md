# Подтверждение выхода

Figma `6:70`: явная кнопка «Выйти» в шапке сначала открывает короткий диалог с предупреждением о несохранённом тексте. «Остаться» и Escape закрывают его, возвращают фокус на кнопку и сохраняют текущий черновик, сессию и browser storage. Для безопасного выбора начальный фокус стоит на «Остаться». Native dialog ограничивает фокус; используются существующие Card/Button, Manrope, радиус24px и мобильная раскладка без новой графики.

Намерение выхода связано с владельцем и точным SessionTicket. Смена аккаунта/жизненного цикла сессии закрывает его, старое подтверждение не действует для следующего входа. Решение одноразовое и защищено от двойного клика. Само открытие/отмена не отправляет запросов.

После явного подтверждения вызывается прежняя `logout()` без изменения её порядка: немедленная локальная очистка и инвалидирование других вкладок идут до независимого запроса отзыва с10-секундным timeout. При сетевой ошибке данные уже скрыты, но UI не утверждает успешный отзыв: сохраняются `logoutUnconfirmed`, блокировка входа и отдельная команда «Повторить выход». Повтор не требует новой модалки. Автоматический отзыв сессии/отказ401/смена пароля также не перехватываются подтверждением.

Unit-тесты проверяют одноразовый выбор, отмену, смену владельца и SessionTicket, dispose. Desktop/mobile сценарии дополнительно проверяют фокус, Escape, сохранность storage/черновика без POST, очистку до отложенного revoke, повторный клик, старую модалку при cross-tab invalidation; существующие logout privacy и network-failure tests продолжают проходить через явное подтверждение. Новых API, миграций, внешней аналитики, AI/платежей/провайдеров нет. Сервер и автодеплой не меняются.
