# Публичный сертификат GigaChat

`russian-trusted-root.crt` — публичный корневой CA, не приватный ключ.
Источник: <https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt>,
указанный в [инструкции GigaChat](https://developers.sber.ru/docs/ru/gigachat/certificates).
Сохранённая копия проверена 26 октября 2026 года: CA, самоподпись, срок действия
до 27 февраля 2032 года и закреплённый SHA-256 файла
`aa800ef345422d6158c6fafe1c06c429dbda21c3df4bb1ccb45a920ec1111399`.

Отпечаток сертификата SHA-256:
`D2:6D:2D:02:31:B7:C3:9F:92:CC:73:85:12:BA:54:10:35:19:E4:40:5D:68:B5:BD:70:3E:97:88:CA:8E:CF:31`.

Docker копирует сертификат только в образ API. Транспорт GigaChat добавляет его
только для двух закреплённых HTTPS-адресов авторизации и генерации. Проверка TLS
сохраняется; системное хранилище, глобальные агенты, RouterAI, платежи и почта
не получают дополнительного доверия. Подмена файла или истечение его срока
останавливает проверку сборки и запуск нового профиля.

В образах Web и Jobs сертификата нет. При замене нужна отдельная проверка
официального источника, отпечатка и срока, обновление закреплённых значений,
проверки и новый выпуск. Сертификат не обновляется автоматически при сборке.
