# CityGo — помощник при переезде

CityGo помогает человеку подготовиться к переезду и освоиться в новом городе.
Продуктовый принцип: **немного информации → полезный результат → следующий
добровольный шаг**, а не длинная обязательная анкета до первой помощи.

## Актуальное направление: диалог, не опросник

Корректирующая итерация от 18 октября сохраняет БД, CI/CD и историю Git.
Новый пользователь Web/Expo начинает разговор с координатором **без анкеты**;
бюджет, срок и обстоятельства уточняются в диалоге. Добавлены роли `user`,
`admin`, `super_admin`, смена пароля и отдельный закрытый bootstrap администратора.
Регистрация: пароль от 6 до 128 любых символов, без дополнительных требований.

Это первый рабочий срез разговорного прототипа, не весь Figma: структурированные
результаты, избранное, три пользовательских режима и API Bubble ещё впереди.
Старый жилищный путь остаётся совместимым для ранее заполненных профилей;
форма больше не является входным экраном. Ни этот PR, ни merge сами по себе
не удаляют серверные аккаунты и не создают публичный `admin/admin`.
[Границы, безопасная очистка и bootstrap](docs/implementation/conversation-restart.md).

Ниже сохранён исторический срез после PR #75; не используйте его описание
обязательной анкеты как новое продуктовое требование.

Ближайшая цель — закрытый Web-пилот для **20 человек, переезжающих из городов
России в Москву**. Первый законченный сценарий — подготовка к поиску и просмотру
жилья; на обращения отвечает владелец CityGo. Работа, бюджет переезда, билеты,
перевозка вещей, городские сервисы и новое окружение — дальнейшее развитие.

## Что работает сейчас

Срез после [PR #75](https://github.com/CityGo-Tech/citygo-platform/pull/75),
4 октября 2026. Это состояние кода, **не подтверждение готовности публичного сервиса**.

- Web: регистрация, вход, сохранение анкеты, план из двух жилищных квестов,
  потоковый AI-чат, история, завершение и XP. Административный раздел — `/admin`.
- API и БД: пользовательские сессии, проверка владельца данных, принадлежность
  квеста плану, транзакционное начисление XP и миграции PostgreSQL/PGlite.
- AI: адаптеры RouterAI, прямого OpenAI и GigaChat; ручное переключение,
  согласия, лимиты и бюджет. Предпочтение владельца — RouterAI / DeepSeek Pro;
  чистый клон не включает реальные вызовы автоматически.
- Деньги: отдельный пользовательский AI-баланс, разовый приветственный бонус
  500 ₽ после подтверждения администратором и учёт подтверждённой стоимости
  RouterAI без наценки. Платёжное пополнение пока не подключено.
- Expo: мобильный клиент на общих контрактах и API, защищённое хранение сессии,
  анкета, план, чат и XP. Экспорт JS-бандла — не установочный APK.
- Дизайн: сохранённый снимок токенов Figma, Web-компоненты, локальные шрифты
  и оптимизированные персонажи. Это не непрерывная двусторонняя синхронизация.
- Эксплуатация: Docker, HTTPS-ingress, контролируемое обновление из `main`,
  шифрованные резервные копии и политика хранения. Состояние работающего
  сервера и свежесть восстановления проверяются отдельно.

### Важное отличие прототипа от целевого R1

Сегодня первоначальный путь всё ещё требует старую анкету. Завершение квеста
проверяет наличие полного ответа Housing Navigator после старта, но **не
полезность подготовленного результата**. Обращение к человеку сохраняется,
однако полноценного независимого операторского процесса ещё нет.

В PR #75 приняты контракты постепенного сбора данных: неизвестные и пропущенные
ответы, отделение предположений от фактов, ревизии результата и явное
подтверждение. Их хранение, новый интерфейс и серверная проверка завершения —
следующие задачи **CG-012 → CG-013/CG-014**. Наличие схем не означает, что новый
сценарий уже доступен пользователю. Подробности — в [статусе](docs/project-status.md).

## Запуск с чистого клона

Нужны доступ к приватному репозиторию, Git, Node.js 24 LTS и pnpm **10.15.0**.
Команды ниже предполагают доступный Corepack. Если его нет, установите
закреплённую версию pnpm; не обновляйте lockfile ради запуска.

```sh
git clone https://github.com/CityGo-Tech/citygo-platform.git
cd citygo-platform
corepack pnpm install --frozen-lockfile
corepack pnpm dev
```

Откройте [Web](http://localhost:3000). API работает на
[localhost:4000](http://localhost:4000/health). Запуск собирает общие пакеты
и применяет миграции. Для первого запуска Docker и `.env` не нужны:
локальная БД PGlite хранится в игнорируемой папке `.local/database`.
Без настройки AI интерфейс честно сообщает о недоступности модели.

Это режим разработки, не сервер для внешних тестировщиков. `pnpm start` —
production-режим с отдельными требованиями к PostgreSQL, HTTPS и прокси.
Подключение реального AI требует серверных ключей, настройки политики,
бюджета и согласия пользователя — одного ключа недостаточно.

- [Подробный локальный запуск и частые проблемы](docs/runbooks/local-development.md).
- [Запуск Expo на телефоне](apps/mobile/README.md).
- [Настройка AI](docs/runbooks/ai-providers.md) и [списание AI-баланса](docs/runbooks/ai-credit-charging.md).

## Проверки перед изменениями

```sh
pnpm check
pnpm browser:install
pnpm test:e2e
pnpm mobile:export
```

`check` включает линтер, типы, тесты, сборку и проверку запуска. E2E использует
отдельный тестовый сервер: остановите `dev`, чтобы освободить порты 3000/4000.
`mobile:export` создаёт Android/iOS JS-бандлы, не подписанные приложения.
CI отдельно проверяет PostgreSQL и контейнерный сценарий. Тесты не требуют
платных модельных запросов. [Подробнее о проверках](CONTRIBUTING.md#проверки).

## Правила безопасности и поставки

Не публикуйте ключи, `.env`, дампы БД, анкеты и диалоги в Git, PR, issues или чатах.
Секреты AI принадлежат API, не Web или мобильному клиенту. Не отключайте TLS,
согласия, права доступа и бюджетные ограничения ради успешного теста.

Работа ведётся в отдельных ветках через PR. **Merge в `main` может запустить
обновление Cloud.ru**, если автоматический deploy включён; это относится и к
документационным PR. См. [процесс разработки](CONTRIBUTING.md) и
[автоматическое развёртывание](docs/runbooks/automatic-main-deployment.md).

Все разделы и источники: [документация CityGo](docs/README.md).
